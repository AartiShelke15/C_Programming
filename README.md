# C Programming – Logic Building

## About
This repository contains my C programming practice programs and assignments, focusing on logic building and code improvement.

## How to Execute
1. Open the `.c` file in VS Code and save it.
2. Open CMD and navigate to the program folder.
3. Compile the program:
   ```cmd
   gcc program1.c -o myexe
   ```
4. Run the program:
   ```cmd
   myexe.exe
   ```
